# [Week 10 polymorphism] — C# Object-Oriented Programming

## Overview
This repository contains the C# starter code and practical examples for **week 10**. It is designed to demonstrate core object-oriented programming principles using Visual Studio 2026.

## Key concepts covered
- Implementing Polymorphism
- Implementing a menu system

## Getting started

### Clone directly in Visual Studio 2026
1. Fork this repo. Then copy the repo link.
2. Open Visual Studio 2026 and select **Clone a repository**.
3. Paste this repo's HTTPS URL into the **Repository location** field.
4. Choose a local folder on your machine and click **Clone**.
